## Condition Notebook Flow

1. Install the pinned stack (vLLM 0.30.0 → torch 2.13/cu130, transformers 5.16.1; `jevk5` v0.3.0 without dependencies;
   incompatible Colab torchaudio/torchcodec packages are uninstalled).
2. Parameters (form) → `Experiment(**params)` → folder `results/<COND>/<COND>_<RUN_TAG>_<hash8>/`.
3. Environment (GPU, host, packages, probe) · 4. Snapshots + hash verification · 5. Preliminary preflight (includes
   native J reference in a subprocess) · 6. vLLM engines (J first, then G or B) · 7. Preflight with engines ·
   8. Warm-up with dev · 9. Resumable main loop · 10. Final manifest + zips.

## Key Decisions

* **One copy of G, 4 batched requests** (SHARED4): minimum cost for generating 4 candidates in parallel.
* **Engines in subprocesses** (`enable_multiprocessing=True`): allows G+J on the same GPU without the notebook ever
  creating a CUDA context. Explicit `kv_cache_memory_bytes` + `gpu_memory_utilization=0.05` (only to pass the second
  engine's free-memory check).
* **IDs, not text**: continuation always resends accepted IDs; the prefix is never re-tokenized.
* **Predictions without gold**: grading takes place in `07_analisis` with the analysis bundle.
* **Resumption**: key `sha256(config_hash|problem_id|seed|condition|profile)`; a prediction is written at the end
  of the case (fsync), so a disconnection never leaves a half-finished case marked as done.
